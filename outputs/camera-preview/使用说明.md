# 双摄像头采集工作台

程序仍位于同目录的「双摄像头预览.app」，窗口标题已改为「双摄像头采集工作台」。

## 1. 相机调试

先选 camera-1 或 camera-2，再按右侧四个分区调整。

| 分区 | 操作 |
| --- | --- |
| 取景 | 设置分辨率、帧率与设备变焦，调整预览旋转和镜像 |
| 对焦 | 用 1× / 1.5× / 2× / 4× 检查细节，自动或手动调焦，再锁定此路 |
| 色彩 | 在两路取样同一块灰卡或同材质白色参照，再匹配颜色；需要时手动微调 |
| 校正 | 显示网格、点选四角校正透视、导入镜头标定 |

设备变焦改变相机的取景范围，影响后续采集；其数值是设备刻度，未确认对应的光学倍率。变焦后需重新检查清晰度并锁定。

在「对焦」点「双路点选同一颗种子」，依次点击上、下画面里的同一颗种子，就能同时查看两个局部。点「保存原图和种子局部」会保留两路全幅原图，并导出各自原像素的局部 PNG 和裁切坐标。1× 恢复完整画面。手动对焦的数值采用设备刻度。

用「点选种子附近寻焦并锁定」保存焦点时，未启用畸变或透视校正的画面也会保存原图中的对焦参照点。采集时程序会短暂检查锁定位置附近的候选帧，按参照点周围的边缘清晰度选图，然后恢复锁定位置。采集记录保留入选帧的焦点刻度。移动种子或改动机位后，重新点选参照点。

「高级 · 两路同步对焦」默认折叠。底层图像控制收在「色彩 → 高级 · 硬件图像参数」。

「保存测试对照」导出两路原图及软件校正图；「参数配置」菜单提供参数导入、导出及重置。

软件色彩、方向与几何校正用于预览和校正导出。当前定时采集保存相机原图。

## 2. 定时采集

依次设置频率、确认防睡眠选项、拍摄一组测试照片，检查结果后再启动定时采集。

60 分钟按每小时整点拍摄；其他间隔从启用或保存时起算。可填 1–1440 分钟。测试照片不会启用定时任务。

任务启动后可保存新频率或暂停。保持 Mac 接电并开盖，可以锁屏。程序的防闲置睡眠只在程序打开且任务启用时生效。退出程序后，macOS 后台定时仍可能继续执行，程序提供的防睡眠会结束。

采集结果区显示最近拍摄时间，并可打开数据文件夹。权限检查和日志入口收在「高级 · 权限与运行诊断」。

## 3. 数据浏览

左侧选择时间节点，右侧对照 camera-1 / camera-2 原图、任务编号与开始后的整点小时。可打开单张原图或任务文件夹。

## 4. 设备信息

查看底层参数的范围、步进、默认值、读回值，以及原生视频格式、USB / 固件和厂商扩展声明。可导出设备报告。此页用于能力检查，日常调整在「相机调试」。
